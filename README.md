# استودیو نمایار

نسخه آماده انتشار وب‌سایت استودیو نمایار با GitHub Pages.

## نام Repository پیشنهادی
`studio-namayar`

## اجرای محلی
```bash
npm install
npm run dev
```

## Build
```bash
npm install
npm run build
```

## انتشار
Workflow داخل `.github/workflows/deploy.yml` برای GitHub Pages آماده شده است.
